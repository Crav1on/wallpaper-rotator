# Wallpaper Rotator

A small Windows tray app that rotates desktop wallpapers per monitor, each monitor drawing from its own folder on its own timer.

Windows Slideshow uses one folder for all monitors. This app lets the user set a different wallpaper on each connected monitor, rotating through images from a folder matched to that monitor's resolution, automatically and on a timer. It is meant to be light on resources, with no network access, no elevated rights, and no telemetry, and to survive docking, monitor changes, sleep/resume, and reboots.
